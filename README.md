# AR Plant Shopping 🌱

An Augmented Reality (AR) plant shopping application developed using Unity. The project aims to let users preview plants in their real-world environment using a mobile device.

## Project Overview

AR Plant Shopping demonstrates how augmented reality can improve the online plant-shopping experience. Users can detect a suitable surface through their device's camera and preview a virtual plant in that environment.

## Objectives

- Explore the use of AR in e-commerce.
- Detect horizontal surfaces in the real world.
- Place and preview virtual plants in an environment.
- Learn how Unity and AR Foundation support mobile AR applications.

## Features

- Camera-based augmented reality.
- Horizontal plane detection.
- Virtual plant placement.
- Plant prefabs managed in Unity.

*Verify each feature on your device before presenting it as completed.*

## Technologies Used

- Unity 2022.3.62f3
- C#
- AR Foundation
- ARCore XR Plugin
- Android

## Project Structure

- `Assets/` — scenes, scripts, materials, prefabs, and plant assets.
- `Packages/` — Unity package dependencies.
- `ProjectSettings/` — Unity project configuration.
- `Documentation/` — screenshots and project report.

## How to Open the Project

1. Install Unity 2022.3.62f3 using Unity Hub.
2. Install Android Build Support, including the Android SDK & NDK tools and OpenJDK.
3. Clone or download this repository.
4. Open the project folder using Unity Hub.
5. Allow Unity to import assets and resolve packages.
6. Connect a compatible Android device and configure the Android build settings.
7. Build and test the application.

## Requirements

- Windows PC with Unity installed.
- Android device compatible with ARCore for AR testing.
- Camera permission enabled when prompted.

## Limitations

Device compatibility and AR performance depend on the phone's hardware and ARCore support. Features should be tested on a physical device.
